# Through Different Eyes
### An Interactive Faculty Development Activity

**Through Different Eyes** is an immersive, scenario-based simulation that invites faculty to experience a virtual "first day of class" through the perspective of students encountering inaccessible course materials. Using a split-screen design, participants see what an instructor intended alongside what a student with a disability actually experiences — including progressive degradation effects (blur, scrambled text, garbled captions, impossible timers) that make invisible barriers visceral and memorable.

The simulation includes four scenarios covering low vision/blindness, deaf/hard of hearing, cognitive/dyslexia-related barriers, and motor/mobility challenges — each ending in a decision point, empathy-building feedback, and actionable fixes faculty can implement immediately.
